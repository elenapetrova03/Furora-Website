FURORA – IMAGE NAMES
Put every image in the folder shown, with exactly this name. All lowercase. .jpg is best; .jpeg, .png and .webp also work.
If you put images straight in the img folder (without the subfolders) the site finds them too.
Open image-check.html to see which images were found.
If a file is missing, the site shows a placeholder, so you can add them one at a time.
Suggested sizes: product, shop, swap, dog and breed photos 800 x 600 px; hero photos 1000 x 1250 px; vets 600 x 600 px.
